# BMI Calculator

## Project Description
This project is a simple Python program that calculates Body Mass Index (BMI) using weight and height.

## Features
- Accepts weight in kilograms.
- Accepts height in metres.
- Calculates BMI and displays the result to two decimal places.
- Displays the corresponding BMI category.
- Handles invalid and non-positive inputs.

## Technologies Used
- Python 3

## How to Run
1. Install Python 3.
2. Open the project folder in VS Code.
3. Open the terminal.
4. Run the command:

```bash
python main.py
```

## Sample Output
```text
Enter weight in kg: 60
Enter height in metres: 1.65
Your BMI is: 22.04
Category: Normal
```
